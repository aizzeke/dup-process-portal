# ДУП · Навигатор процессов — MVP

Статический read-only портал, рассчитанный на GitHub Pages.

## Что уже сделано

- главная страница-каталог процессов;
- отдельная страница процесса «Реализация инвестиционного проекта»;
- три вкладки: **Схема / Документ / Моя роль**;
- BPMN viewer на `bpmn-js` с zoom, fit-to-view, fullscreen и скачиванием `.bpmn`;
- встроенный просмотр PDF;
- отдельная ссылка на DOCX, если он добавлен;
- iframe для исходного `dup_game_1.html`;
- относительные пути — проект нормально работает в подпапке GitHub Pages;
- нет backend, БД, Docker, авторизации и сборки Node.js.

## Важно про `dup_game_1.html`

Исходный файл **специально не переписывался**.

Положите ваш оригинальный файл без изменений сюда:

```text
processes/realization/guide/dup_game_1.html
```

Сайт просто откроет его в iframe.

## Как добавить настоящий BPMN

Замените файл:

```text
processes/realization/diagram/realization.bpmn
```

Сейчас там находится маленькая демонстрационная BPMN-заглушка, чтобы viewer можно было проверить сразу.

## Как добавить документ

Положите:

```text
processes/realization/document/regulation.pdf
processes/realization/document/regulation.docx   # необязательно
```

PDF показывается прямо на странице. DOCX используется только для скачивания.

## Локальный запуск Windows

Не открывайте `index.html` двойным кликом: браузер может блокировать `fetch()` локальных BPMN-файлов.

Запустите:

```text
start-local.cmd
```

или вручную:

```powershell
py -m http.server 8080
```

Затем откройте:

```text
http://localhost:8080/
```

## Внешняя зависимость

Для BPMN viewer сейчас используется зафиксированная версия `bpmn-js@18.26.0` с CDN jsDelivr.
Если корпоративная сеть блокирует CDN, позже библиотеку можно сохранить внутрь `assets/vendor/` и убрать внешние ссылки. Сам портал от backend не зависит.
